# 🎬 Ignition WAN RunPod Deployment Guide

> This file is regenerated by `./template.sh` when you create a new template. The values below reflect the defaults — see README.md for the full reference.

## Quick Start

1. **Generate template**: Run `./template.sh` (or `./template.sh --deploy` for direct API deployment)
2. **Import template**: Upload `ignition_template.json` to RunPod → Templates
3. **Deploy pod**: Select template, choose GPU (RTX 5090 or A100 40GB), deploy
4. **Access**: ComfyUI on port 8188, file browser on port 8080

## Access URLs

- **ComfyUI**: `http://[your-pod-id]-8188.proxy.runpod.net`
- **File Browser**: `http://[your-pod-id]-8080.proxy.runpod.net` (login: `admin` / your password)

## WAN 2.2 Model Presets

Set `HUGGINGFACE_MODELS` to one of these bundle keys at pod creation:

| Key | Use Case | Size |
|-----|----------|------|
| `wan2.2_t2v_bundle` | Text-to-video (LightX2V 4-step) | ~15GB |
| `wan2.2_i2v_bundle` | Image-to-video (LightX2V 4-step) | ~15GB |
| `wan2.2_full_bundle` | Both T2V + I2V | ~29GB |
| `svi_i2v_bundle` | SVI Pro long video (~40s, no LightX2V) | ~30GB |
| `svi_nsfw_i2v_bundle` | SVI Pro long video, uncensored | ~32GB |
| `remix_nsfw_i2v_bundle` | NSFW I2V — FX-FeiHou Remix v3.0 | ~24GB |
| `phr00t_mega_nsfw_bundle` | NSFW I2V+T2V — Phr00t MEGA v12.2 | ~15GB |

## Restarting ComfyUI

```bash
/workspace/scripts/restart-comfyui.sh   # soft restart, models preserved
/workspace/scripts/stop-pod.sh           # hard stop + nuke (deletes all data)
```
